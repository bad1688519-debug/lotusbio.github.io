How to Review a Peptide COA Before Wholesale Purchase

Buyer guide · Research-use materials

A certificate of analysis (COA) is one part of a supplier review. It should help you connect a specific batch to a product, a test method and a testing record. This guide is for procurement and documentation review. It does not provide medical or therapeutic advice.

1. Match the product and batch

Check the product name, product code and batch or lot number.

Confirm that the COA matches the material and packaging you are asking about.

Ask the supplier to explain any difference between a catalog name and the name on the report.

2. Check the issuing laboratory

Look for the laboratory name, report date, report number and contact details. If an independent report is referenced, ask how the sample was identified and whether the report applies to the same batch.

3. Read the analytical sections

Identity: identify the stated method, such as mass spectrometry, and the acceptance result.

Purity: check the stated method, result, specification and units. Do not compare numbers without checking that the methods are comparable.

Appearance and handling: confirm the description is consistent with the supplied form and packaging.

Record what the report actually establishes

Use a separate entry for identity, purity and content. A percentage from one method should not be used as the answer to all three questions.

Identity
Which compound or material form was tested, by which method, and against which reference or acceptance criterion?
Chromatographic purity
What chromatographic method and calculation were used? An area percentage does not by itself establish the mass of peptide in a vial.
Measured content
Was content measured separately, in what units and on what basis? Check whether the result covers bulk material or finished vials and whether water or counterions affect the stated basis.

A catalog-format example

An SM10 Semaglutide inquiry refers to a catalog pack of ten vials labelled 10 mg each. A bulk-material purity report alone does not verify the measured content of those ten vials. Request the proposed batch reference, the tested sample form and any available finished-vial content result. This is a purchasing example, not a claim that a particular report or test is available.

Keep a report verification record

  • Requested product, material form, catalog code and proposed batch.
  • Report number, issue date, issuing laboratory and sample identifier.
  • Each test method, result, units and stated acceptance criterion.
  • Whether the document covers bulk material, finished vials or another sample.
  • Open questions and the supplier's written clarification.

If a report is presented as independent testing, verify it through the laboratory's own official contact route when possible. Resolve mismatched batch or sample identifiers before using the report to approve an order. See the third-party testing procurement guide for related questions.

4. Ask for missing procurement details

Before purchase, confirm available pack sizes, minimum order quantity, lead time, shipping documents and the process for receiving the batch documents. Keep the written response with your purchasing records.

5. Questions to send a supplier

Which batch does this report cover?

Which test method and specification were used?

Can the report number be verified with the issuing laboratory?

Which documents will be supplied with the shipment?

Connect a report to the requested supply format

Record the material form and proposed batch before choosing a document. A bulk-material COA does not by itself establish finished-vial content, and a reference document does not establish the specification of a different batch.

  • Bulk raw material: start with the Report access code lookup →, then request the document matching the material and batch being quoted.
  • Catalog vials: identify the product and pack format, then check the sample form and test scope in the documentation overview.
  • Custom synthesis: define requested analytical documents during the project review; available testing and final specifications are confirmed for that project.

Find documents by supply format

Use a document that matches the identity, molecular form, sample format and batch under review. A familiar product name alone is not enough to connect a report to a quotation.

  • Raw-material example: open the Open report with access code →. Locate the product identity, report date, specification, analytical methods and stated results in the file. Then review the Tirzepatide bulk sourcing requirements. This example does not establish the result for a later supply batch.
  • Finished-vial sample example: open the Open report with access code → and review its sample code, batch, analysis date, test scope and limitations. It is a separate document type from a raw-material COA.
  • Variants and catalog labels: compare the separate CJC-1295 with-DAC and without-DAC documents. For the TB500 raw-material reference, check the identity printed in the file before comparing it with a fragment or another catalog format.

The Report access code lookup → contains watermarked distribution copies. The Report access code lookup → retains its own issuer and scope statements. Publication and a supplier watermark do not independently authenticate results or confer laboratory accreditation.

For procurement in any destination market

Include the destination country, total quantity and unit, proposed material form, documentation language and any buyer-required tests when requesting a quotation. Confirm preparation time separately from transport time, and agree which batch documents will accompany the proposed supply.
