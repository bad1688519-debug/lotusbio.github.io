# LotusBio Wholesale Website

GitHub + Vercel ready static website for **lbiopeptides.com**.

## Deploy with GitHub + Vercel

1. Create a new GitHub repository, for example `lotusbio-wholesale`.
2. Upload every file and folder from this project to the repository root.
3. In Vercel choose **Add New → Project → Import Git Repository**.
4. Import the repository. No framework or build command is required.
5. After deploy, open **Vercel → Project → Settings → Domains**.
6. Add `lbiopeptides.com` and `www.lbiopeptides.com`.
7. Add the DNS records shown by Vercel at your domain provider. Do not delete MX/SPF/DKIM/DMARC records used by email.
8. Set `lbiopeptides.com` as the primary domain and redirect `www` to it.
9. Submit `https://lbiopeptides.com/sitemap.xml` in Google Search Console.
